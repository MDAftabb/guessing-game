# Number Guessing Game

A command-line number guessing game built with Python.

## Features
- Three difficulty levels (easy, medium, hard)
- Limited tries, with warmer/colder and even/odd hints
- High scores saved between sessions

## How to run
    python game.py
    python game.py --difficulty hard

## What I learned
- Functions, loops, dictionaries, and input validation
- Reading and writing JSON files
- Command-line arguments with argparse
